교체를 검토하는 시점

도어락은 소모품이 들어가는 전자 제품이라 오래 쓰면 모터, 키패드, 기판 같은 부품이 차례로 약해집니다. 다만 한두 가지 증상만으로 바로 교체할 필요는 없습니다. 도어가드24는 부품 교체나 조정으로 정상 작동이 가능하면 수리를 먼저 진행하고, 다음과 같을 때 교체를 상의합니다.

  • 같은 고장이 반복되고 내부 기판이 부식되거나 침수된 흔적이 있는 경우
  • 단종 등으로 맞는 부품을 구할 수 없는 경우
  • 수리 비용이 새 제품 설치와 크게 다르지 않은 경우
  • 열쇠형 보조키를 쓰다가 번호·카드·지문 인증으로 바꾸고 싶은 경우

사용 기간과 비용 구성은 도어락 교체 주기와 비용 구성에서, 판단 기준은 수리와 교체 판단 기준에서 더 자세히 다룹니다.

기존 타공을 그대로 쓸 수 있는지

교체 작업에서 가장 먼저 보는 것은 문에 이미 뚫려 있는 구멍입니다. 새 제품이 기존 타공 위치와 크기에 맞으면 추가 가공 없이 설치할 수 있지만, 위치가 다르면 구멍을 더 내거나 기존 구멍을 가리는 보강판이 필요합니다. 보강판이나 추가 가공이 들어가면 그만큼 작업과 비용이 늘어나므로 제품을 정하기 전에 이 부분을 먼저 설명합니다. 문 두께, 문 재질, 방화문 여부, 문과 문틀 사이 간격도 함께 확인합니다.

일체형과 푸시풀 중 어떤 것이 맞는지

일체형 도어락은 본체가 비교적 단순하고 설치 부담이 적어 원룸, 사무실, 보조 출입문 등에 많이 쓰입니다. 푸시풀 도어락은 손잡이를 밀거나 당기는 동작으로 문을 여닫을 수 있어 짐을 들고 드나드는 일이 잦은 현관에서 편합니다. 다만 푸시풀은 본체가 커서 문 구조와 기존 손잡이 위치를 더 꼼꼼히 봐야 합니다. 두 방식의 차이는 푸시풀 도어락과 일체형 도어락 비교에 정리했습니다.

현재 취급하는 일체형 제품은 락프로 H2000, 마스터즈 7100, 유니코 L3200이고, 푸시풀 제품은 락프로 H5000F, 마스터즈 8000FS, 마스터즈 8600FS입니다. 전체 목록은 제품 페이지에 있습니다.

교체 작업 순서

  1. 기존 도어락과 문 상태 확인, 기존 타공 치수 확인
  2. 설치 가능한 제품과 추가 작업(보강판, 추가 타공 등), 비용을 작업 전에 안내
  3. 기존 도어락 분리 후 새 제품 설치
  4. 걸쇠와 문틀 받침의 위치를 맞추고 자동 잠금, 열림·닫힘 동작 점검
  5. 비밀번호와 카드키, 지문 등 인증 수단 등록 후 사용 방법 설명

기존 타공을 그대로 쓰는 경우는 작업이 비교적 짧고, 추가 가공이나 보강판이 필요하면 시간이 더 걸립니다. 정확한 작업 범위는 현장에서 문을 보고 판단합니다.

교체 후 확인할 것

설치가 끝나면 문을 여러 번 여닫아 걸쇠가 문틀에 걸리지 않는지, 문이 닫힌 뒤 자동으로 잠기는지 함께 확인합니다. 문이 처져 있는 집은 새 도어락을 달아도 같은 걸림이 생길 수 있어 필요하면 문틀 받침 위치를 조정합니다. 사용하던 카드키는 새 제품과 호환되지 않을 수 있으므로 새 제품에 맞게 다시 등록합니다.

Q.고장 났으면 무조건 교체해야 하나요?

그렇지 않습니다.

부품 교체나 조정으로 정상 작동이 가능하면 수리를 먼저 진행하고, 수리가 어렵거나 노후가 심할 때만 상의 후 교체합니다.

Q.기존 구멍이 새 도어락과 맞지 않으면 어떻게 하나요?

추가 타공을 하거나 기존 구멍을 가리는 보강판을 씁니다.

이 경우 작업과 비용이 늘어나므로 제품을 정하기 전에 미리 안내합니다.

Q.쓰던 카드키를 새 도어락에서도 쓸 수 있나요?

제품마다

지원하는 카드 방식이 달라 호환되지 않을 수 있습니다. 교체 후에는 새 제품에 맞는 카드로 다시 등록하는 것이 일반적입니다.
